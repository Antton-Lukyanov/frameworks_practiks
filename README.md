# Сервис сдачи заданий

Консольное приложение для учёта студентов, учебных заданий и проверки их сдачи.

## Назначение

Приложение позволяет вести учёт студентов и учебных заданий, фиксировать факт сдачи задания, проверять допустимый размер файла и выставлять результат по баллам.

## Целевая аудитория

Студенты (сдают задания) и преподаватели (проверяют и выставляют оценки).

## Предметная область

Процесс сдачи и проверки учебных заданий в учебном заведении.

Основные объекты предметной области:

- **Student** — студент;
- **Task** — учебное задание;
- **Submission** — факт сдачи задания студентом.

Студент сдаёт задание, создавая объект `Submission`. Одно задание не может быть сдано одним студентом дважды, пока активная сдача не отменена. Отменённая сдача не блокирует повторную сдачу.

## Основные классы

### Student — студент

Атрибуты:
- `id` — идентификатор;
- `name` — имя;
- `group` — группа.

Методы:
- `__init__()` — конструктор;
- `__str__()` — строковое представление;
- `from_data()` — создание из данных JSON (`@classmethod`);
- `to_data()` — преобразование в словарь для JSON.

### Task — учебное задание

Атрибуты:
- `id` — идентификатор;
- `title` — название;
- `max_score` — максимальный балл;
- `deadline` — дедлайн.

Методы:
- `__init__()`, `__str__()`;
- `is_expired()` — проверка истечения срока;
- `from_data()` (`@classmethod`), `to_data()`.

### Submission — сдача задания

Атрибуты:
- `id` — идентификатор;
- `student` — объект `Student`;
- `task` — объект `Task`;
- `file_name` — имя файла;
- `file_size_mb` — размер файла;
- `score` — балл;
- `submission_date` — дата;
- `is_cancelled` — признак отмены.

Методы:
- `__init__()`, `__str__()`;
- `cancel()` — отмена сдачи;
- `get_result()` — текстовый результат по баллам;
- `from_data()` (`@classmethod`), `to_data()`.

## Взаимодействие объектов

Объект `Submission` связывает `Student` и `Task`:

    submission.student.name
    submission.task.title

В JSON сохраняются идентификаторы связанных объектов (`student_id`, `task_id`). При загрузке модуль `storage.py` находит соответствующие объекты `Student` и `Task` и передаёт их в конструктор `Submission`.

## Функции, оставшиеся обычными

- `get_task_status()`, `check_file_size()`, `get_result()` — перенесены из ПР1, не относятся к состоянию объекта;
- `add_student()`, `find_student()`, `add_task()`, `find_task()`, `create_submission()`, `cancel_submission()`, `get_statistics()` — операции над коллекциями объектов;
- `input_str()`, `input_int()`, `input_float()` — вспомогательные функции ввода (`utils.py`);
- `load_*()`, `save_*()` — операции с внешним хранилищем (`storage.py`).

## Хранение данных

Данные хранятся в JSON-файлах `data/students.json`, `data/tasks.json`, `data/submissions.json`. При загрузке JSON преобразуется в объекты `Student`, `Task`, `Submission`. При сохранении объекты преобразуются обратно в словари через `to_data()`.
