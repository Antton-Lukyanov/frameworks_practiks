# Сервис сдачи заданий

Консольный проект из ПР3 дополнен веб-интерфейсом на Django (ПР5). Приложение
помогает просматривать учебные задания, студентов и их сдачи.

## Предметная область

- `Student` — студент с именем и учебной группой;
- `Task` — задание с максимальным баллом и дедлайном;
- `Submission` — сдача задания студентом с файлом, датой, результатом и статусом.

Сдача связывает объекты студента и задания. Повторно сдать задание можно после
отмены предыдущей активной сдачи.

## Технологии и хранение

- Python 3.10+;
- Django 5.2;
- HTML, CSS и Bootstrap 5.3;
- JSON-файлы в каталоге `data/` как источник предметных данных;
- pytest и flake8 для консольного проекта.

На этом этапе Django использует существующие классы из `models/` и функции
загрузки из `storage.py`. Предметные Django ORM-модели, миграции и запись данных
через веб-интерфейс не используются. Консольная программа `main.py` и её тесты
сохранены.

## Страницы веб-интерфейса

| URL | Страница | View-функция |
| --- | --- | --- |
| `/` | Главная страница и навигация | `homepage.views.index()` |
| `/students/` | Список студентов | `students.views.student_list()` |
| `/students/<int:student_id>/` | Карточка студента | `students.views.student_detail()` |
| `/tasks/` | Список заданий | `tasks.views.task_list()` |
| `/tasks/<int:task_id>/` | Карточка задания | `tasks.views.task_detail()` |
| `/submissions/` | Список сдач | `submissions.views.submission_list()` |
| `/submissions/<int:submission_id>/` | Карточка сдачи | `submissions.views.submission_detail()` |

Если объект с указанным идентификатором отсутствует, карточка возвращает HTTP
404. Неизвестный URL показывает общую страницу 404.

HTML-страницы формируются общим помощником `homepage.views.page()`. Bootstrap
подключается через CDN, общие правила оформления добавлены в каркас `page()`.

## Структура Django

- `task_service/` — настройки проекта и корневые маршруты;
- `homepage/` — главная страница и общий HTML-каркас;
- `students/`, `tasks/`, `submissions/` — страницы соответствующих сущностей;
- `models/`, `storage.py`, `data/` — прежняя объектная модель и JSON-хранилище;
- `main.py`, `tests/` — прежняя консольная версия и её тесты.

## Установка и запуск

Создайте виртуальное окружение и установите зависимости:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Проверьте конфигурацию и запустите локальный сервер:

```powershell
python manage.py check
python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. Доступны адреса `localhost` и
`127.0.0.1`.

Консольная версия по-прежнему запускается отдельно:

```powershell
python main.py
```

## Состояние проекта

Веб-интерфейс предназначен для чтения данных из JSON и отображает списки и
карточки сущностей. Добавление и изменение записей через формы, пользователи и
переход на Django ORM относятся к следующим этапам проекта.
