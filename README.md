# Сервис сдачи заданий

Консольное приложение для учёта студентов, учебных заданий и проверки их сдачи.

## Назначение

Приложение позволяет вести учёт студентов и учебных заданий, фиксировать факт сдачи задания, проверять допустимый размер файла и выставлять результат по баллам.

## Целевая аудитория

Студенты (сдают задания) и преподаватели (проверяют и выставляют оценки).

## Предметная область

Процесс сдачи и проверки учебных заданий в учебном заведении.

## Основные сущности

- Студент
- Задание
- Файл (сдача)
- Результат

## Основные функции

- добавление и поиск студентов;
- добавление и поиск заданий;
- проверка статуса сдачи задания;
- проверка допустимого размера файла;
- создание и отмена сдачи;
- выставление результата по баллам;
- просмотр статистики по сдачам;
- сохранение и загрузка данных в JSON.

## Структура проекта

- main.py — точка запуска и меню;
- students.py — работа со студентами;
- tasks.py — работа с заданиями;
- submissions.py — работа со сдачами;
- storage.py — сохранение и загрузка данных (JSON);
- utils.py — вспомогательные функции ввода;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования

- Python 3.10+;
- pytest;
- flake8.

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    pytest

## Проверка качества кода
