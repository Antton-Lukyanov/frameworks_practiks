# Сервис сдачи заданий

## Назначение
Приложение для сдачи студентами учебных заданий и проверки их преподавателем.

## Целевая аудитория
Студенты и преподаватели учебных заведений.

## Предметная область
Процесс сдачи и проверки учебных заданий.

## Основные сущности
- Студент
- Задание
- Файл
- Результат

## Основные функции
- Проверка статуса сдачи задания
- Проверка допустимого размера файла
- Выставление результата по баллам

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
